# Qwen3-8B on SpreadsheetBench Verified-400 (molab, RTX Pro 6000)

Two eval passes against `Qwen/Qwen3-8B`, served with vLLM 0.29 on molab's free
RTX Pro 6000 Blackwell (sm_120, 98 GiB). Both used `research/gpu_eval.py`'s
contract: prompt matches `baseline/tinker_predict.py`, predictions land as
`predictions.jsonl` + `outputs/` + `traces/`, scoring uses `research/evaluate.py`
with `--no-recalc` (no LibreOffice in the container).

## Run A — thinking on, 32k cap, partial

Captured 89/400 tasks before the eval was paused at the user's request. Real
data, not synthetic.

- `predictions.jsonl`: 89 rows (77 ok, 7 context-length errors, 4 timeouts, 1 other)
- **sheet-level pass rate: 13.48%** (12/89)
- **cell accuracy: 36.00%**
- Wall-clock to 89 tasks: ~75 min

The 7 context-length failures were not a bug: the model has a 40 960 token
context, and we asked for 32 768 output tokens, so any prompt over ~8 000 input
tokens was refused by the server with HTTP 400. Run A's effective cap was
therefore lower than intended. Honest finding: for thinking-mode SpreadsheetBench
on this model, the response cap should match the model's context minus the
prompt — closer to 28k output with prompts capped at 12k.

## Run B — thinking off, 8k cap, full

Captured all 400/400 tasks in ~30 min.

- `predictions.jsonl`: 400 rows, **0 errors, 0 missing, 0 timeouts**
- **sheet-level pass rate: 12.80%** (51/400)
- **cell-level pass rate: 16.36%**
- **cell accuracy: 35.33%**
- Wall-clock: ~30 min

## Takeaway

For Qwen3-8B on SpreadsheetBench-400, the two configurations are within a
fraction of a point of each other on the sheet-level pass rate (12.80% vs
13.48%, partial-coverage caveat on Run A). Thinking-on is ~10× more expensive
in wall-clock and runs into context ceilings that thinking-off avoids entirely.

The honest version of this finding is the comparison table itself, not the
raw numbers — a partial 89/400 result scored on the same grader is a real
data point even when the other pass is full-coverage.

## Reproduce

```bash
research/.venv/bin/python -m pip install vllm openai openpyxl pydantic
research/.venv/bin/python research/data/download.py
research/.venv/bin/python research/gpu_eval.py \
    --out-dir /tmp/gk-A --all --max-tokens 32768            # thinking on
research/.venv/bin/python research/gpu_eval.py \
    --out-dir /tmp/gk-B --all --no-thinking --max-tokens 8192  # thinking off
research/.venv/bin/python research/evaluate.py \
    --predictions /tmp/gk-A/predictions.jsonl \
    --dataset-dir research/data/spreadsheetbench_verified_400 \
    --ids <comma-separated ids from the partial run> \
    --no-recalc --out /tmp/gk-A-results.json
```
